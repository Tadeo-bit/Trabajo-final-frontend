# WhatsApp Clone (React)

## Descripción
Aplicación de mensajería estilo WhatsApp Web desarrollada en React.

## Funcionalidades
- Lista de contactos
- Envío y eliminación de mensajes
- Indicador de mensajes no leídos (derivado del estado)
- Persistencia con localStorage
- Diseño responsive

## Tecnologías
- React
- CSS
- LocalStorage

## Aprendizajes
- Manejo de estado en React
- Derivación de datos (unread desde messages)
- Diseño responsive
